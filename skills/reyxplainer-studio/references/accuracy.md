# Technical accuracy
For every episode distinguish the model from actual implementation. Verify claims with authoritative documentation when uncertain; record sources and assumptions in the episode notes. A human or independent technical reviewer must check the final script.
Buffer example: char buf[4] reserves four C char slots. In the illustrated ASCII string copy, CAT plus NUL fits; CATS plus NUL requires five slots. An unchecked copy can write NUL past the buffer. A longer string can write several bytes past it. In C this is undefined behavior, not a guaranteed sequential overwrite or crash. Adjacent cells are a conceptual illustration, not a real stack layout. Bounds checking or rejecting/truncating input safely prevents this example. Never imply that every buffer overflow is exploitable or that all input is ASCII.
