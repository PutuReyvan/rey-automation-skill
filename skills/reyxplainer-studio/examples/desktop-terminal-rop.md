# Desktop/terminal ROP episode: what changed after review

Rey requested a 2D pixelated explainer for return oriented programming in a CTF. The first draft used generic mechanism cards. He clarified that he wanted a Windows- or Linux-like wallpaper desktop, a cursor opening Terminal, and the ROP mechanism shown as a terminal trace. The revised 64-second pilot used one persistent desktop workspace and changed the terminal command and internal state for each beat: NX hook, normal return, changed saved address, existing-code gadget, stack-driven chain, NX comparison, defenses and recap. Commands and addresses were illustrative, not a real exploit run.

The second correction was about captions. The draft used individual white word boxes with a green active word. Rey wanted the same visible treatment as his Claude-rendered videos. Four local MP4 references were inspected: `CCouu8L4o5Z0vQWuHF_OcQ.mp4`, `onad.mp4`, `openport.mp4`, and `SswnBcYyBzMrhyWTSE4pPA.mp4`. Their shared treatment was heavy white uppercase text, a thick black outline/shadow, one yellow active word, no boxes, and short centered phrases around the y=1240–1450 band in 1080×1920 frames. The ROP captions were rebuilt from 189 exact narration-script words with measured local alignment and manual phrase cuts; awkward automatic groups such as `... TO / THE` were removed.

For future episodes, inspect the actual reference clips when available. Reproduce the observed caption grammar rather than copying the ROP lesson's desktop setting into unrelated briefs.
