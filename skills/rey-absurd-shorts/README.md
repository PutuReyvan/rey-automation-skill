# Rey Absurd Shorts v0.1

A Claude Code and Codex skill for original 60–90 second absurd vertical stories with a blocky toy-game 3D cast, active character acting, fast scene variety, narration, word-highlight captions, music and sound effects.

Install this skill together with `reyxplainer-studio`, because it reuses that package's Remotion initializer, audio pipeline and technical QA tools.

Example request:

```text
Use rey-absurd-shorts to make a 90-second English vertical story:
In this town, everyone must keep performing a bizarre ritual or the monster below the street wakes up.
Give me the narration and storyboard first. Use an original blocky 3D cast and a serious documentary tone.
```

The skill treats “Roblox-like” as a broad blocky game-world direction and requires original characters and assets.
