# Rey Horror Shorts v0.1

A Claude Code and Codex skill for 60–90 second vertical horror stories with serious narration, coherent supernatural rules, original 3D or 2D visuals and logically resolved endings.

Install it with `reyxplainer-studio` for Remotion production and `inkbeat-shorts` when using the blocky toon 3D mode.

Example request:

```text
Use rey-horror-shorts to draft an 80–90 second English story beginning with “In this town...”. The premise may be impossible, but the monster must follow a consistent rule. Establish its weakness before the climax, let the protagonist test and exploit it, defeat or securely contain the threat, and end with the town's lasting solution. Give me the voice-over script first.
```
